***Github-Demo***


This repository demonstrates managing a DevOps project with Git best practices including branching, pull requests, tagging, and documentation.

***Project Overview ***

- Terraform code to provision Docker containers
- Git workflow with main, dev, and feature branches
- Pull request based merging
- Version tagging and execution logs

***Branches***

- `main`: Production-ready code
- `dev`: Development integration branch
- `feature/*`: Feature branches for isolated changes
